# Proyecto MMD

## Descripción
Proyecto grupal desarrollado para practicar el trabajo colaborativo utilizando Git, GitHub e IntelliJ IDEA.

## Integrantes
- Mario
- Mireia
- Darío

## Tecnologías utilizadas
- Git
- GitHub
- IntelliJ IDEA

## Requisitos
- Tener Git instalado.
- Tener IntelliJ IDEA instalado.
- Tener acceso al repositorio de GitHub.

## Instalación
Clonar el repositorio:

```bash
git clone https://github.com/daryjrr/proyecto_mmd.git
```

Abrir la carpeta del proyecto en IntelliJ IDEA.

## Configuración
Comprobar el repositorio y las ramas con:

```bash
git remote -v
git branch
```

## Ejecución
Abrir el proyecto en IntelliJ IDEA y seguir las instrucciones de ejecución correspondientes a la aplicación.

## Estructura del proyecto
- `README.md`: documentación general.
- `.gitignore`: archivos excluidos del control de versiones.
- Otras carpetas: archivos del proyecto.

## Trabajo colaborativo
Cada integrante trabaja en su propia rama. Los cambios se comparten mediante GitHub y se integran en `main` a través de Pull Requests revisados por el equipo.

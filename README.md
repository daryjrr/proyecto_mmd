# Proyecto MMD

## Descripción
Proyecto grupal desarrollado en el módulo de Desarrollo de Aplicaciones Web para practicar el trabajo colaborativo y la gestión de cambios mediante Git, GitHub e IntelliJ IDEA.

## Integrantes
- Mario
- Mireia
- Darío

## Tecnologías utilizadas
- Git para el control de versiones.
- GitHub para compartir el código y revisar los cambios.
- IntelliJ IDEA como entorno de desarrollo.
- Añadir aquí el lenguaje y las tecnologías utilizadas en la aplicación.

## Requisitos
- Tener Git instalado.
- Tener IntelliJ IDEA instalado.
- Tener acceso al repositorio de GitHub.
- Instalar las dependencias necesarias para ejecutar la aplicación, si las hay.

## Instalación
Clonar el repositorio:

```bash
git clone https://github.com/daryjrr/proyecto_mmd.git
```

Abrir la carpeta descargada desde IntelliJ IDEA.

## Configuración
Comprobar la configuración del repositorio:

```bash
git remote -v
git branch
```

Configurar las dependencias y los servicios necesarios según las tecnologías del proyecto.

## Ejecución
Abrir el proyecto en IntelliJ IDEA y seguir las instrucciones de ejecución correspondientes a la aplicación.

## Estructura del proyecto
- `.idea/`: configuración del entorno IntelliJ IDEA.
- `.gitignore`: archivos excluidos del control de versiones.
- `README.md`: documentación general del proyecto.
- `CarpetaMireia/`: carpeta de trabajo del proyecto.

## Trabajo colaborativo
Cada integrante trabaja en su propia rama. Los cambios se comparten mediante GitHub y se integran en `main` después de revisarlos mediante Pull Requests.

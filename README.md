## Instalación
Clonar el repositorio:

```bash
git clone https://github.com/daryjrr/proyecto_mmd.git
```

Abrir la carpeta descargada desde IntelliJ IDEA.

## Configuración
Comprobar la configuración del repositorio con:

```bash
git remote -v
git branch
```

Configurar las dependencias y los servicios necesarios según las tecnologías del proyecto.

## Estructura del proyecto
- `.idea/`: configuración del entorno IntelliJ IDEA.
- `.gitignore`: archivos excluidos del control de versiones.
- `README.md`: documentación general del proyecto.
- `docs/`: documentación adicional, si existe.
- Otras carpetas: código fuente y recursos de la aplicación.

## Trabajo colaborativo
Cada integrante trabaja en su propia rama. Los cambios se comparten mediante GitHub y se integran en `main` después de su revisión mediante Pull Requests.
